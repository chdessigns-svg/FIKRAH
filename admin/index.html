Backup & Sync

How this works Everything you add here is saved in this browser only (not on a server). To make your edits appear for real site visitors, click Export All Content and send the downloaded fikrah-content-export.json file to whoever deploys the site, so it can replace data/content-seed.json. Use Import Content File to load that file back in on any browser — handy for editing on a different computer, or for sharing drafts with a teammate. Uploaded photos are stored directly in this export file, so large or many photos can make it a big file — compress images before uploading where you can.
